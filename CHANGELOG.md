# TraceMind 0.2.0

**Download:** `TraceMind.exe` below. It's a single file and needs no install. If Windows SmartScreen warns you, click **More info → Run anyway**.

## New in 0.2.0
- **Use your Claude plan.** TraceMind can run the AI through Claude Code with your Pro or Max login, so there's no API key or extra bill. Install Claude Code in PowerShell with `irm https://claude.ai/install.ps1 | iex`, then run `claude` once and sign in.
- **⚡ Build a board.** Describe a board and Claude designs all of it: parts, schematic, placement, routing and checks.
- A cost and usage line in the chat panel.
- The version number now shows in the title bar and in Help → About.

## 0.1.0
- First version: schematic and PCB editors, autorouter, DRC, Gerber/drill/BOM/CPL export, KiCad import and export, and the Claude design agent.
